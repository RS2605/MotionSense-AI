# Data Dictionary

| Column | Meaning |
|---|---|
| row_id | Unique row number |
| subject | Participant ID |
| time_step | Time step within an activity recording |
| activity | Human activity label / target |
| acc_x | Accelerometer X-axis reading |
| acc_y | Accelerometer Y-axis reading |
| acc_z | Accelerometer Z-axis reading |
| gyro_x | Gyroscope X-axis reading |
| gyro_y | Gyroscope Y-axis reading |
| gyro_z | Gyroscope Z-axis reading |
| device | Phone/device label |
| acc_magnitude | Overall acceleration feature |
| gyro_magnitude | Overall gyroscope rotation feature |
| activity_code | Numeric version of activity label for ML |
